# Vyukovy_a_simulacni_program_pro_dopravni_krizovatky
Vytvořte v prostředí Visual Studio (jazyk C#) desktopovou aplikaci pro Windows Forms s verzováním na GitHubu. Aplikace bude sloužit jako interaktivní výukový a procvičovací systém pro výuku pravidel silničního provozu a správného pořadí průjezdu vozidel dopravními křižovatkami.
Uživatel si v režimu výuky prohlédne krok za krokem průjezd vozidel se zdůvodněním platných pravidel (přednost zprava, hlavní/vedlejší silnice, semafory) a v režimu procvičování si sám interaktivním klikáním na auta volí pořadí jejich odjezdu s okamžitou zpětnou vazbou a vyhodnocením chyb.
Aplikace bude využívat několik předdefinovaných grafických šablon křižovatek (např. T-křižovatka, klasická 4-ramenná křižovatka, křižovatka se semafory). Konkrétní scénáře, rozmístění vozidel a jejich cílové směry budou načítány ze strukturovaných souborů ve formátu JSON nebo XML. Vykreslování bude realizováno pomocí rozhraní GDI+ s jednoduchou animací pohybu aut po přímých trasách.
